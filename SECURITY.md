# Security Policy

## Supported versions

Security fixes are provided for the current release of
`Megaraz.ResultPattern.AspNetCore`, which supports .NET 8, .NET 9, and .NET 10.
Earlier package versions are not supported.

## Reporting a vulnerability

Please report vulnerabilities privately using [GitHub Security
Advisories](https://github.com/Megaraz/Megaraz.ResultPattern.AspNetCore/security/advisories/new).
Do not report security vulnerabilities through public GitHub issues.

Include a description of the issue, affected package version, reproduction
steps or proof of concept, potential impact, and any suggested mitigation.
We will acknowledge the report, investigate it, and coordinate disclosure and
a fix when appropriate.
